# Pasta de imagens — Amanteigados Lívia

Coloque aqui as **fotos reais** com estes nomes exatos. Assim que os arquivos
existirem, o site substitui automaticamente as ilustrações pelas fotos
(sem precisar mexer no código).

| Arquivo | Onde aparece | Proporção ideal | Tamanho sugerido |
|---------|--------------|-----------------|------------------|
| `hero.jpg` | Imagem grande do topo (prato + tulipas + caixa) | ~6:5 (paisagem) | 1200 × 1000 px |
| `encomendas.jpg` | 1º card — Encomendas | 3:2 (paisagem) | 900 × 600 px |
| `festas.jpg` | 2º card — Festas | 3:2 (paisagem) | 900 × 600 px |
| `personalizados.jpg` | 3º card — Personalizados | 3:2 (paisagem) | 900 × 600 px |
| `logo.png` | Selo circular do cabeçalho/rodapé (opcional) | 1:1 (quadrado) | 400 × 400 px |

**Dicas:**
- Formato `.jpg` para fotos (mais leve) e `.png` para o logo (fundo transparente).
- Se não houver `logo.png`, o selo desenhado no código é usado como fallback.
- Mantenha os nomes em minúsculas e sem acentos.
